# Leanerizer
Linux tool that lets you select files to remove before backup.

Created by gemini on prompt descriptions. Use at own risk. 

Compile with 

gcc main.c -o leanerizer `pkg-config --cflags --libs gtk4` -Wno-deprecated-declarations
